帮助文档

解析 APK

将唤境 (Evk) 游戏引擎导出的 APK 解压后，选择解压目录进行解析。

源文件夹

应包含 assets/www/data.json 的目录。通常是 APK 解压后的根目录。

输出文件夹

留空则默认输出到 parsed_projects/源文件夹名/。输出内容：

  • project.json — 项目元数据（精灵、动画、音频、布局）
  • sprites/ — 每帧一个 PNG 文件，命名格式: {对象}_{动画}_{帧号}.png
  • audio/ — 音频文件（已恢复中文文件名）

数据结构

唤境 data.json 的关键结构：

  • project[3] — 布局数组
  • 每个布局的 [7] — 动画数组
  • 每个动画的 [7] — 帧数组
  • 每帧格式: ["assets/images/XXX.png", spriteId, x, y, w, h, scale, anchorX, anchorY, polygon, ...]

其中 x, y 是在图集 (atlas) PNG 中的裁切坐标，anchorX/Y 是锚点归一化坐标 (0~1)。

查看项目

动画播放器

  • 左侧树形列表: 布局 → 对象 → 动画
  • 点击动画名称播放
  • 控制按钮: 上一帧 / 播放暂停 / 停止 / 下一帧 / 重置视图
  • 速度选择: 0.25x ~ 4x
  • 循环 / 锚点 / 碰撞体 可视化

画布操作

  • 中键拖拽 — 平移画布
  • 滚轮 — 缩放（围绕鼠标位置）
  • 双击 — 重置视图到 100%

导出帧图

点击播放器中的「导出帧图」按钮，会将当前动画的所有帧按锚点位置对齐后导出为 ZIP 文件。

每帧图片尺寸相同，锚点位于画布中心。适用于在其他工具中使用。

对象搜索

左侧树形列表顶部有搜索框，可按名称过滤对象和动画。

API

方法路径说明
GET/api/projects已解析项目列表
GET/api/project/:name项目摘要
GET/api/project/:name/sprites精灵元数据
GET/api/project/:name/animations动画树
GET/api/project/:name/audio音频列表
POST/api/parse开始解析 {source, output}
GET/api/parse/status?jobKey=轮询解析进度
GET/api/file/:name/*获取项目文件
POST/api/export-frames导出帧图为 ZIP
POST/api/export-evk导出为 evk 工程

环境变量

变量默认值说明
PORT3000服务器端口
PROJECTS_DIR../parsed_projects已解析项目存储目录
SOURCES_DIR..扫描 APK 源文件的根目录

依赖

  • Node.js ≥ 14
  • Python 3 + Pillow (pip install Pillow)
  • Express (npm install 自动安装)
